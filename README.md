# 🚀 Zain ul Abdin Baig — Developer Portfolio

A modern, interactive, and fully responsive developer portfolio built for **Zain ul Abdin Baig** — Full-Stack Developer specializing in **.NET, Angular, and Django**.

🔗 **Live / Local**: Open `index.html` in any browser.

---

## ✨ Features

- **Interactive Bash Terminal**: Explore Zain's resume interactively with commands like `help`, `about`, `skills`, `projects`, `experience`, `education`, `certs`, `contact`, and `clear`.
- **Three.js Particle Universe**: Interactive 3D particle background with mouse parallax effects.
- **Dynamic 3D Orbital Tech Stack**: Interactive orbiting skills icons (.NET, Angular, Python, TypeScript, Django, Oracle DB, Kotlin, Firebase, GitHub) that scale and glow on hover.
- **GSAP & ScrollTrigger Animations**: Smooth entrance and scroll-triggered animations.
- **Working Contact Form**: Integrated with **EmailJS** for instant message delivery directly to inbox, with a direct mailto fallback.
- **Fully Responsive**: Optimized for Mobile, Tablet, Laptop, and Ultra-wide screens with an animated frosted-glass mobile navigation drawer.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (custom CSS variables, glassmorphism, responsive grid & flexbox), Vanilla JavaScript (ES6+)
- **Libraries**:
  - [Three.js](https://threejs.org/) — 3D interactive particle background
  - [GSAP & ScrollTrigger](https://greensock.com/gsap/) — Smooth timeline & scroll animations
  - [Typed.js](https://mattboldt.com/demos/typed-js/) — Dynamic typing effect
  - [EmailJS](https://www.emailjs.com/) — Client-side email dispatching without backend servers
